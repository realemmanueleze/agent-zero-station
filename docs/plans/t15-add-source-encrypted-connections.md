## Goal

A founder adds live sources from `/channels` (Sign in with Google and/or paste). Secrets sit in a ledger `connections` table as AES-256-GCM envelopes. Connecting never sends. Approve still owns send. Browser never sees `STATION_MASTER_KEY` or plaintext tokens.

- `applyLedgerMigration` reads only `migrations/001_ledger.sql` (`packages/station/src/postgres.ts:39`). Must apply every `migrations/00*.sql` in order.

## Architecture

```
browser  /channels  Add source
   │  never talks to :19174
   ▼
cockpit :19173
   │  JSON workerFetch → /connections*
   │  302 workerRedirect → /oauth/google/*  (Bearer server-side only)
   ▼
worker 127.0.0.1:19174
   │  envelope.ts encrypt/decrypt
   │  connections.ts store
   │  oauth-google.ts PKCE Map + code exchange
   ▼
Postgres connections  ciphertext only
   │
   ▼
Approve: load decision.account → decrypt on worker →
  createGmailApiTransport | createSmtpTransportFromFields →
  commitSend(draft, transport)
```

OAuth origin:

```
start origin = STATION_PUBLIC_URL if set
             else http://127.0.0.1:19173
if requested origin not in that set → connections.invalid (or auth.oauth_state)
redirect_uri = {allowedOrigin}/oauth/google/callback
```

PKCE Map:

```
start:  if size >= CAP → reject
        set(state, { verifier, expiresAt })
callback: delete(state) FIRST
          then check existed + not expired
          miss → auth.oauth_state
```

## Schema

`migrations/002_connections.sql` (also add `account` + `kind` on `decisions` here, or `003_decisions_account.sql` if you want the table create split — prefer **one** `002` that: creates `connections`, and `ALTER TABLE decisions ADD COLUMN IF NOT EXISTS account TEXT`, `ADD COLUMN IF NOT EXISTS kind TEXT`).

`connections` columns (snake_case):

- `id` text PK (UUID, stable on upsert of `(kind, account)`)
- `tenant_id` text = `account` in v1
- `kind` text (`email` | `slack` | `obsidian` | `db` | `mcp`)
- `account` text
- `label` text
- `status` text (`pending` | `live` | `error` | `needs_reauth`)
- `key_id` text (`v1`)
- `nonce` bytea (12 bytes)
- `tag` bytea
- `ciphertext` bytea
- `created_at`, `updated_at`

Unique `(kind, account)`. Index `(tenant_id, kind)`.

Envelope: AES-256-GCM via Node `crypto` (`createCipheriv("aes-256-gcm")`). Fresh 12-byte nonce every write. AAD = `id|tenantId|kind` rebuilt from the row, never stored beside the blob. Key = `STATION_MASTER_KEY` (32 raw bytes or 64-char hex). T15 tests use a 32-byte key.

`applyLedgerMigration`: glob `migrations/00*.sql`, sort, apply in order. In-memory `getStation()` gets an equivalent `Map` so T15 runs without Postgres.

Worker derives `account` and ignores client `account`:

| Kind | account |
| --- | --- |
| email paste | imapUser |
| email OAuth | Gmail profile email |
| slack | workspaceId (paste) or Slack team id (OAuth) |
| obsidian | vaultPath |
| db | stable UUID minted on first insert (not the label) |
| mcp | name |

## Worker modules

`packages/station/src/envelope.ts` — `encrypt` / `decrypt`. Throws `connections.encrypt_failed` / `connections.decrypt_failed`. AAD mismatch throws `StationError`.

`packages/station/src/connections.ts` — load/upsert/delete/list metadata. `useEmailConnection(account)` lives **here** (not in channels): decrypt, call channel transport factory, drop plaintext.

`packages/station/src/oauth-google.ts` — PKCE Map, start URL, callback code exchange, profile GET, persist envelope, status `live`.

`packages/station/src/oauth-slack.ts` — same Map pattern, Slack OAuth v2, persist bot token, status `live`.

`packages/station/src/email-producer.ts` — Gmail list or IMAP SEARCH → ledger signal + parked decision with `account`, `kind`, `to`.

`packages/station/src/station.ts` `handleWorker` dispatches:

- `GET /connections`
- `POST /connections` — paste envelopes only. Body with `transport: "gmail"` + refresh token → `connections.invalid`.
- `POST /connections/:id/test` — decrypt once, live ping, `live` or `error`. Never SMTP DATA / Gmail send.
- `DELETE /connections/:id`
- `POST /connections/rotate-keys`
- `GET /oauth/google/start`, `GET /oauth/slack/start`, worker callback handlers (cockpit proxy only)

`send.approve`: if `decision.account` has a live email row → worker `useEmailConnection` → `commitSend`. Else fixture `callProvider` / env SMTP (no live row for that `(kind, account)`).

Missing or `needs_reauth` on Approve → that error code, state stays `parked`.
